# Khám phá decoded JWT claims

Chỉ là JSON claims giả lập. Viewer không decode token, kiểm tra chữ ký, xác minh issuer/audience hoặc quyết định quyền truy cập.

```data-inspector
title: Claims không phải bằng chứng token hợp lệ
json: |-
  {
    "iss": "https://issuer.example.invalid",
    "sub": "u_001",
    "aud": ["demo-api"],
    "exp": 1735689600,
    "roles": ["reader"],
    "https://example.invalid/tenant": "demo",
    "custom~flag": true
  }
annotations:
  - id: expiry
    pointer: /exp
    title: exp là NumericDate theo contract
    description: Giá trị minh họa, không phải token còn hiệu lực. Viewer không tự validate thời gian.
  - id: namespaced
    pointer: /https:~1~1example.invalid~1tenant
    title: Dấu / trong key được escape thành ~1
    description: JSON Pointer trỏ đúng key namespace, không tách URL thành các field con.
  - id: tilde
    pointer: /custom~0flag
    title: Dấu ~ được escape thành ~0
    description: Path copy ra theo JSON Pointer RFC 6901, không phải JavaScript dot notation.
```
