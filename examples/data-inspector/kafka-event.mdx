# Event có số nguyên lớn

Transcript dữ liệu minh họa, không kết nối Kafka. Số sequence được giữ dưới dạng lexeme JSON; viewer không chuyển nó sang JavaScript Number.

```data-inspector
title: Khám phá event envelope
json: |-
  {
    "eventId": "evt_demo_001",
    "sequence": 9007199254740993,
    "headers": [
      {"key": "content-type", "value": "application/json"}
    ],
    "value": {
      "orderId": "order_001",
      "amount": "19.90",
      "currency": "USD",
      "items": [{"sku": "book-01", "quantity": 2}]
    }
  }
annotations:
  - id: sequence
    pointer: /sequence
    title: Không làm tròn số nguyên lớn
    description: Copy value giữ nguyên 9007199254740993. Consumer xử lý số này cần chọn kiểu dữ liệu phù hợp.
  - id: amount
    pointer: /value/amount
    title: Decimal dưới dạng string là lựa chọn của contract
    description: Viewer chỉ hiển thị dữ liệu, không xác minh định dạng tiền tệ hoặc tính toán giá trị.
```
