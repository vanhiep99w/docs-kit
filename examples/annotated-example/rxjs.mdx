# Pipeline RxJS

Ví dụ dùng RxJS 7.x; of() phát đồng bộ.

```annotated
title: filter và map không sửa source
language: typescript
code: |
  import { filter, map, of } from 'rxjs';

  const result$ = of(1, 2, 3).pipe(
    filter((value) => value % 2 === 0),
    map((value) => value * 10),
  );

  result$.subscribe(console.log);
annotations:
  - id: pipeline
    title: Ghép các phép biến đổi
    description: filter giữ số 2; map đổi 2 thành 20. Khai báo pipeline không bắt đầu execution của source này.
    ranges: [[3, 6]]
  - id: subscribe
    title: Bắt đầu execution
    description: subscribe khiến source phát các giá trị; console.log nhận số 20.
    ranges: [[8, 8]]
```
