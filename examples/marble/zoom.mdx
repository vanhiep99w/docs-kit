# Marble zoom — đổi khoảng cách, giữ frame

Zoom chỉ thay khoảng cách ngang của trục dùng chung, không đổi frame, kích thước marker, font hoặc thứ tự sự kiện.
Không autoplay hoặc thực thi RxJS. Khi không JavaScript, diagram vẫn hiển thị ở 48px/frame và có bảng sự kiện native.

```marble
title: Nhóm cùng frame và cancellation
zoom: true
rows:
  - id: source
    label: source$
    marble: '--(ab)----c-----|'
    kind: source
  - id: inner
    label: inner đang hoạt động
    marble: '--^---x-!-----'
    kind: inner
values:
  a: Input A
  b: Input B cùng frame
  c: Input C
  x: Kết quả minh họa
annotations:
  - id: cancel
    row: inner
    frames: [8, 8]
    title: Unsubscribe ở frame 8
    description: Đây là dữ liệu tác giả khai báo; zoom không suy ra hay kiểm chứng cancellation của operator.
```
