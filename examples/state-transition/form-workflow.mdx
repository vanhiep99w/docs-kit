# Form submission — success, retry và cancellation

Mô hình UI đơn giản, không phải form có input hoặc API thật. Khi chọn nhánh, các điều kiện được coi là giả định của tác giả.
Không tự validate input, thực thi fetch, nhận response hoặc abort request.

```state-transition
title: Luồng gửi form có retry
assumptions: Chỉ một submission đang chờ. Success và Cancelled là trạng thái kết thúc trong ví dụ; việc bỏ qua response muộn cần được implementation thật xử lý, không được component này kiểm chứng.
initial: idle
states:
  - id: idle
    label: Idle
    description: Chưa gửi form trong mô hình.
  - id: submitting
    label: Submitting
    description: Đang chờ kết quả do người đọc chọn, không có request thật.
  - id: failed
    label: Failed
    description: Có thể thử lại hoặc quay về sửa input.
  - id: success
    label: Success
    terminal: true
    description: Kết thúc luồng minh họa này, không tự redirect hoặc mở trang khác.
  - id: cancelled
    label: Cancelled
    terminal: true
    description: Kết thúc nhánh cancellation của ví dụ, không thực thi AbortController.
transitions:
  - id: submit
    from: idle
    to: submitting
    event: SUBMIT
    guard: Giả định input hợp lệ.
    description: Chuyển tới trạng thái chờ; không đánh giá validation function.
    effects:
      - Gửi payload trong implementation thật; không gửi trong docs.
  - id: duplicate
    from: submitting
    to: submitting
    event: SUBMIT
    description: Mô hình bỏ qua thao tác gửi lặp bằng self-loop, không phát thêm request.
  - id: resolve
    from: submitting
    to: success
    event: RESOLVE
    description: Giả định submission thành công; Success là terminal được tác giả khai báo.
  - id: reject
    from: submitting
    to: failed
    event: REJECT
    description: Giả định submission thất bại; không suy ra lỗi từ HTTP status hoặc payload.
  - id: cancel
    from: submitting
    to: cancelled
    event: CANCEL
    description: Chọn nhánh cancellation, không thực thi thao tác hủy thật.
    effects:
      - Yêu cầu hủy và bỏ qua response muộn trong implementation thật (chỉ mô tả).
  - id: retry
    from: failed
    to: submitting
    event: RETRY
    guard: Giả định được phép retry và payload vẫn hợp lệ.
    description: Retry là nhánh được chọn thủ công; không có backoff, delay hoặc retry loop tự chạy.
  - id: edit
    from: failed
    to: idle
    event: EDIT
    description: Quay lại sửa form trong mô hình; không tạo input hoặc thay dữ liệu người dùng.
```
