# Java — publication qua volatile

Giả định: một shared object đã được khởi tạo trước khi start hai thread, `int data = 0`,
`volatile boolean ready = false`. Chỉ writer ghi `data` và `ready`, không có ghi khác sau publication.

```java
// Writer                  // Reader
data = 42;                 if (ready) {
ready = true;                  int result = data;
                           }
```

Diagram chỉ mô tả nhánh mà reader đọc `ready == true` từ lần ghi của writer.
Không hứa reader sẽ được schedule, sẽ thấy `true` trong một thời hạn hoặc sẽ đi vào nhánh này trong mọi execution.
Bước logic không phải timestamp CPU, vị trí trái/phải tự nó không chứng minh happens-before.

Nguồn: [JLS 21 §17.4.4 — Synchronization Order](https://docs.oracle.com/javase/specs/jls/se21/html/jls-17.html#jls-17.4.4)
và [§17.4.5 — Happens-before Order](https://docs.oracle.com/javase/specs/jls/se21/html/jls-17.html#jls-17.4.5).
Bỏ `volatile` không được thay thế bằng việc thêm `sleep` hoặc kéo hai marker ra xa nhau.
