# D2: viewer, nhiều board và tài nguyên dùng chung

D2 vẫn chạy qua `@d2lang/d2`/WASM lúc build. Không thêm CLI, Go, server render công khai hay compiler vào browser. Chỉ sử dụng D2/MDX do tác giả đáng tin cậy quản lý; SVG được nhúng trực tiếp, không phải sanitizer.

## 1. Bật tương tác khi cần

Đăng ký **cả hai** component, giữ import CSS hiện có:

```tsx
import { D2Diagram } from '@vanhiep99w/docs-kit/components/d2';
import { D2InteractiveDiagram } from '@vanhiep99w/docs-kit/components/d2-interactive';

const components = { D2Diagram, D2InteractiveDiagram };
```

```css
@import '@vanhiep99w/docs-kit/styles/d2.css';
```

Không cần biến `mdx-components.tsx` thành client component. `D2InteractiveDiagram` là boundary riêng. Diagram cũ vẫn sinh `D2Diagram`, không import viewer. Diagram opt-in có một client launcher nhỏ; chunk chứa controls chỉ tải khi bấm **Explore**. Compiler/WASM luôn ở build process.

````mdx
```d2 interactive title="Đường đi của request"
direction: right
client -> api -> database
```
````

Sau khi mở: fit, zoom/reset, kéo chuột để pan, mở rộng qua native dialog, xem/copy D2 và tải SVG theo theme đang dùng. Bàn phím khi focus canvas: `+`, `-`, `0`; với steps có thêm trái/phải. Mobile giữ cuộn và pinch của browser, không chặn cử chỉ trang. Dialog hỗ trợ Escape, focus trap của browser và trả focus về nút mở.

Controls dùng font/theme của website, không phụ thuộc Fumadocs. Nhãn controls hiện bằng tiếng Anh. Chưa có API dịch nhãn. Clipboard cần secure context và quyền browser; nếu không copy được, người đọc vẫn chọn text trong phần source.

## 2. Steps: diễn giải từng bước

````mdx
```d2 mode=steps title="Dirty read và rollback"
account: "Số dư: 10M"
tx1: TX1
tx2: TX2
steps: {
  "1 · UPDATE": {
    account: "Số dư: 0 — chưa commit"
    tx1 -> account: UPDATE
  }
  "2 · Dirty read": {
    tx2 -> account: SELECT → 0
    account.tooltip: "Chỉ xảy ra khi DB/isolation level cho phép dirty read."
  }
  "3 · ROLLBACK": {
    account: "Số dư: 10M — đã rollback"
    tx1 -> account: ROLLBACK
  }
}
```
````

`mode=steps` tự bật tương tác, chỉ lấy board cơ sở và nhánh `steps` của nó, không chèn các scenarios/layers không liên quan. Mỗi step kế thừa step trước. Có Previous/Next, số bước và Play/Pause; không tự chạy khi tải trang. Play dừng ở bước cuối và khi tab bị ẩn. Không tự phát khi bật `prefers-reduced-motion`.

SVG light/dark của từng bước được build sẵn; chuyển bước không compile lại. Mặc định tối đa 32 board (cho phép cấu hình 1–128). Nhiều board làm tăng HTML/MDX và thời gian build, nên tách ví dụ dài thành các phần nhỏ.

## 3. Scenario tabs

````mdx
```d2 mode=tabs title="Cache hit và timeout"
client -> api -> database
scenarios: {
  "Cache hit": {
    api -> cache
    (api -> database)[0]: null
  }
  "Timeout": {
    (api -> database)[0].style.stroke-dash: 4
    api -> client: Retry later
  }
}
```
````

Tabs gồm board cơ sở và nhánh `scenarios`, không lấy steps/layers không liên quan. Mỗi scenario kế thừa board cơ sở, không kế thừa scenario trước. Tab hỗ trợ roving focus, trái/phải, Home/End và liên kết ARIA với panel.

## 4. Layers: xem từ kiến trúc đến chi tiết

````mdx
```d2 mode=explorer title="Kiến trúc API"
client -> api -> database
api.link: layers.implementation
layers: {
  implementation: {
    controller -> service -> repository
    back: "← Tổng quan" {link: _}
  }
}
```
````

Explorer có danh sách board, breadcrumb và xử lý link board trong SVG. `_` quay về board cha theo ngữ nghĩa D2. Mỗi layer là một board mới, không kế thừa board cơ sở. Mode này duyệt toàn bộ layers/scenarios/steps trong phạm vi target.

Tên board có dấu chấm phải quote: `layers."api.v1"`. Có thể giới hạn phạm vi:

````mdx
```d2 mode=explorer target='layers."api.v1"'
# Source chứa layer api.v1 và các board con của nó...
```
````

`target` cũng dùng được với static để render một board cụ thể, hoặc với steps/tabs để chọn board cơ sở khác. Không nhận wildcard; không có API `elkAlgorithm` vì public SDK hiện tại chưa expose tùy chọn CLI tương ứng.

## 5. Animation

`mode=animation interval=1500` duyệt toàn bộ board trong phạm vi target, có Play/Pause và tải **Animated SVG** do D2 tạo lúc build. Mỗi board giữ 1500 ms; khoảng hợp lệ 250–60000 ms.

Viewer dùng các snapshot để chuyển bước theo điều khiển người đọc. File SVG animation tải xuống là animation native của D2, không phải video hay slideshow React. `mode=steps` không tạo file animation phụ để tránh tăng output không cần thiết.

Mũi tên động vẫn dùng cú pháp D2:

```d2
api -> database: Query {style.animated: true}
```

Ở viewer, motion của SVG tắt mặc định và có nút bật riêng. CSS reduced-motion tắt animation; không tự chạy khi đổi theme. File animated SVG tải xuống giữ hành vi native của D2, không có controls/giới hạn motion của viewer bên ngoài website.

## 6. Click node mở Source Explorer tại chỗ

Ở client provider của host, bọc nội dung bằng adapter:

```tsx
'use client';
import { SourceExplorerProvider, D2SourceLinks } from '@vanhiep99w/docs-kit/components/source-explorer';

export function Providers({ children }: { children: React.ReactNode }) {
  return <SourceExplorerProvider>
    <D2SourceLinks>{children}</D2SourceLinks>
  </SourceExplorerProvider>;
}
```

```d2
controller: Controller {
  tooltip: "Mở implementation"
  link: "?source=demo&file=src/controller.ts&region=entry"
}
```

Adapter hỗ trợ diagram static và interactive, chỉ bắt link source cùng origin/path hiện tại. Giữ Ctrl/Cmd-click, link tab mới, download và link ngoài trang. Query-only link vẫn mở source khi trang đang có hash heading; hash khác được để browser điều hướng bình thường. Không có provider/JS, link vẫn là deep link thông thường. Host phải cung cấp manifest/snapshot giống Source Explorer hiện có.

Có thể dùng `snapshot`, `region`, `lines`. `useSourceExplorer()` được export cho tích hợp tùy biến; trả `null` khi ngoài provider. Không bắt buộc import adapter vào viewer: hai component không kéo dependency runtime của nhau.

## 7. Imports, icons local và font

Ví dụ bố trí project:

```text
content/
  guide.mdx
  diagrams/
    shared.d2
  images/
    database.svg
fonts/
  Regular.ttf
  Bold.ttf
```

```ts
remarkPlugins: [[remarkD2, {
  importsRoot: 'content/diagrams',
  assetsRoot: 'content/images',
  fonts: {
    regular: 'fonts/Regular.ttf',
    bold: 'fonts/Bold.ttf',
    // italic, semibold cũng được hỗ trợ.
  },
}]],
```

Trong `content/guide.mdx`:

````mdx
```d2
...@diagrams/shared
api: API {class: service}
database: Database {icon: ./images/database.svg}
api -> database
```
````

- Imports tương đối với thư mục MDX; file import tiếp tục resolve tương đối theo file `.d2` như D2.
- `importsRoot` là allowlist directory được nạp vào filesystem ảo, không cấp compiler quyền đọc filesystem thật.
- Local icons trong integration này resolve tương đối MDX và được nhúng data URL từ `assetsRoot`. Hỗ trợ SVG/PNG/JPG/JPEG/WebP/GIF. Không bật `assetsRoot` thì giữ URL icon nguyên trạng; URL từ xa không tự được tải/cache/nhúng.
- Roots phải nằm trong `file.cwd`; yêu cầu MDX có đường dẫn trong cwd. Không cho root symlink hoặc symlink trong cây tài nguyên. Dùng thư mục nhỏ, chuyên biệt, không trỏ vào toàn bộ project.
- Giới hạn 256 file tài nguyên và tổng 8 MB, gồm cả fonts. TTF font paths tương đối cwd, không tương đối MDX. Nên cung cấp đủ bốn style; style thiếu dùng font mặc định của D2. SDK chưa expose font-mono tùy chỉnh như CLI.
- Khi sketch bật, custom font thay font vẽ tay theo D2. Font được dùng lúc đo nhãn, không phải đổi CSS sau render.
- Cache key bao gồm toàn bộ nội dung tài nguyên được cung cấp, không chứa absolute root/font paths. Sửa bất kỳ file nào trong allowlist sẽ invalidates cache. Đây là cách bảo thủ, không chỉ theo các import được dùng.

Classes, vars, globs, SQL tables, Markdown, code blocks, LaTeX, legend và tooltip dùng cú pháp D2 bình thường, không có prop React riêng cho từng tính năng. Tooltip native không render Markdown.

## 8. Cấu hình bổ sung

| Option plugin | Default | Ghi chú |
| --- | --- | --- |
| `interactive` | `false` | Bật launcher cho mọi diagram; có thể override theo fence |
| `mode` | `'static'` | `static`, `steps`, `tabs`, `explorer`, `animation`; mode khác static tự bật tương tác |
| `target` | Root | Một đường dẫn board, không wildcard |
| `interval` | `1500` | 250–60000 ms |
| `maxBoards` | `32` | 1–128; chỉ đếm board render trong mode/target đã chọn |
| `fitLabels` | `'auto'` | Hoặc `'off'`; auto giữ vị trí nhãn tác giả chỉ định và ngữ nghĩa sequence/container |
| `themeOverrides` | Theo source | `{light: {B1: '#…'}, dark: {B1: '#…'}}` |
| `importsRoot` | Không bật | Directory `.d2` allowlist |
| `assetsRoot` | Không bật | Directory ảnh local allowlist |
| `fonts` | Font D2 | `regular`, `italic`, `bold`, `semibold`: TTF paths |

Fence hỗ trợ: `title`, `layout`, `interactive`, `mode`, `target`, `interval`, `sketch`, `scale`, `padding`, `lightTheme`, `darkTheme`, `fitLabels`. Boolean nhận flag (`interactive`) hoặc `true`/`false`. Cấu hình lặp/giá trị không hợp lệ báo lỗi có file/vị trí. Metadata không thuộc các key này vẫn được bỏ qua để tương thích host.

````mdx
```d2 interactive sketch=false scale=1 padding=20 lightTheme=4 darkTheme=200 fitLabels=auto title="API"
client -> api
```
````

Fence override plugin. Riêng layout giữ thứ tự cũ: fence → frontmatter `d2Layout` → plugin → ELK. Theme IDs, sketch, padding, scale và layout của integration được ưu tiên hơn `vars.d2-config` trong source; `theme-overrides` và `dark-theme-overrides` trong source vẫn được dùng khi plugin không cấu hình palette tương ứng. Canvas vẫn trong suốt.

## 9. Timeline và bộ mẫu

Mẫu có kiểm thử nằm ở [`examples/d2/`](../examples/d2/):

- `transaction.d2`: steps cho dirty read/rollback.
- `sequence.d2`: timeline tương tác TX1/Database/TX2 với group và notes.
- `scenarios.d2`: cache hit/timeout.
- `architecture.d2`: layer drill-down.
- `timeline.d2`: grid hai cột cho các mốc lịch sử.
- `rich-content.d2` + `shared.d2`: classes/imports, ERD, Markdown, code và source link.

Timeline lịch sử là **categorical layout**, không phải trục thời gian tỷ lệ. D2 không có timeline/Gantt engine chuyên dụng. Timeline transaction dùng `shape: sequence_diagram`; diễn tiến trạng thái dùng `steps`. Không cần tạo DSL mới hay chuyển mọi nội dung text thành diagram.

## 10. Kiểm thử và giới hạn

```bash
npm test
npm run test:pack
# Dùng Chrome local nếu có; hoặc cài Chromium cho Playwright:
npx playwright install chromium
npm run test:browser
# Có thể chọn Chrome executable khác bằng CHROME_PATH.
```

Test browser kiểm tra lazy-load, hydration, zoom/pan, clipboard/download, native dialog/focus, keyboard tabs/steps, autoplay có điều khiển, layer links, source drawer/Back, mobile/dark/reduced-motion và fallback không JS. Unit tests kiểm tra rendering/cache/resources và bộ mẫu. Không cam kết mọi sơ đồ D2 có layout đẹp; viewer chỉ trình bày output của engine.

Không thêm backend CLI, export PNG/PDF/PPTX/GIF hay ELK algorithms ngoài public SDK. Chỉ tải SVG tĩnh/animated. Chưa có editor sửa D2 trong browser, không render source do người dùng nhập. Không có autoformat API ở viewer.
